## 一、产品设计方案

### 1.1 一句话定位与反定位



* **定位**：一台（套）家里本来就在的 eufy 摄像头，把 0–6 岁「会走、会说、会吃」的关键成长瞬间自动变成**家长记得住、社区儿保医生看得懂**的成长记录与沟通材料。

* **魂（沿用赛题）**：家长要的不是 "检测到运动 / 声音"，而是 "**我知道孩子好好的、在按时长大**"—— 把不确定变确定。

* **反定位（红线即差异化）**：


  * 不做诊断、不做发育评分 / 排名、不做 "智商 / 语言迟缓" 判定；

  * 不做视觉营养师：**不猜混合食材、不算热量营养、不判过敏原**；

  * 不做人脸识别、不做声纹识别、不识别 "是谁"（赛题一票否决）；

  * 不预录冒充、不换皮、不做只接不到真设备的纯界面（赛题一票否决）。

### 1.2 政策三层锚点（为什么做 → 对齐哪条 → 看到什么）

| ------ | --------------------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------- |
| **会走** | 健康骨骼 + 体质（户外锻炼、体态、肥胖联防）                                         | WS/T 580 大运动能区；0–6 健康管理 18/24/30/36 月龄发育评估           | 跑停、双脚同时离地跳、踢球、**双脚向前跳过线**、交替上楼           |
| **会说** | **健康心理**：0–6 岁心理行为发育监测比例 **2030 年达 90%**；原话 "探索数智技术… 分级分类精细化管理" | WS/T 580 语言能区；《婴幼儿早期发展服务指南 (试行)》(2025) 语言月龄里程碑       | 对话回应回合、家长确认的词汇 / 短句 Firsts、共同注意（指物 / 追视） |

### 1.3 三尖刀定义卡（每条 = 可观测行为 + 月龄政策锚 + 家长确认 + 诚实边界）

#### 🐰 会走（大运动）｜视觉・全身机位（客厅 / 活动区，S350 云台俯拍）



* **月龄窗**：12–36 月，旗舰聚焦 **24–30 月**。

* **黄金锚点（WS/T 580 大运动 + 早期发展指南）**：24 月跑稳能停、双脚同时离地原地跳、不扶摆腿踢大球；30 月**双脚向前跳**；36 月交替脚上楼 / 单脚站。

* **旗舰任务**：「兔子跳过线」—— 地上贴一条胶带（或一块已知宽度的铺路板 / 门框做**已知物体相对标定，不做精确深度测距**），自动捕捉双脚同时离地并向前跳过线。


  * 距离口径：临床锚点用**月龄里程碑（能不能向前跳）**，不挂英国百分位；个体进步沿用已拍板的**单次纵向进步 Δ（演示中孩子一次进步 5.5cm 是 "个体记录"，不是标准阈值）**。

* **四张任务卡**：红灯停绿灯行（跑停）/ 袋鼠原地跳 / 踢纸球 / 兔子跳过线（旗舰）。

* **判定**：逐帧姿态→双脚离地帧 + 落地帧 + 相对标定换算过线距离；候选→家长三态确认（做到了 / 有时会 / 还不会）。

* **边界**：家用单摄扶走 / 遮挡识别率低（外部证据约 38.9%）；**没拍到≠不会**；报告 "有效观察天数 / 清晰片段数"；倒退、单侧不对称、持续踮脚等只提示就医、不判断。

#### 🗣️ 会说（语言）｜音频为主（soundcore/E21 近端麦克风）+ 视觉辅助共同注意



* **月龄窗**：12–36 月语言爆发期。

* **黄金锚点（早期发展服务指南语言里程碑，原文）**：12 月听懂≥1 个物品名；**18 月说出 3 个有意义的词；24 月说简单句子**；30 月回答简单问题；36 月说出简单故事大部分情节。

* **可做（行为层，最稳）**：


  * **回应式对话回合数**（家长说→孩子应→家长接的 turn-taking 计数，不要求识别每个词）；

  * 家长确认的**不同词去重计数 / 短句 Firsts**（"第一次说三个字"）；

  * 视觉辅助**共同注意**（成人指 / 看→孩子追视 / 指物）。

* **判定**：VAD 切清晰语音段→（mock 脚本 /live 留 ASR 接口）→只统计家长确认的有效样本；嘈杂、多人、电视背景音直接标 "无法判断"。

* **边界（最硬，因远场最难）**：幼儿远场 ASR 错误率高，**只给趋势与样本、不下语言诊断**；**不做声纹 / 身份识别**；样本不足不出提示；持续低于月龄预期且样本充足时，只建议借 30 月龄社区随访向儿保医生咨询。

#### 🥄 会吃（喂养行为）｜视觉・餐桌机位（S350 侧 / 俯视），食物候选家长确认



* **月龄窗**：6–24 月辅食→自主进食窗（习惯延伸至 3 岁）。

* **旗舰是 "怎么吃"（行为层，政策原话可直接视觉判定）**：


  * 自主进食：手抓→用勺→用杯（WS/T 580 适应 / 精细能区）；

  * **饥饱信号与回应**：转头 / 推开 = 饱、前倾 / 张嘴 / 指 = 饿，家长是否回应（回应式喂养）；

  * **进餐看屏**：餐桌有无手机 / 孩子是否看电子屏（指南原话 "进餐时不观看电视、手机"）；

  * **进餐时长**：每餐约 20 分钟、最长≤30 分钟（指南原话，可计时）；

  * **追喂 / 强迫喂养**：识别 "成人端碗追孩子"（中国隔代育儿高频痛点，指南要求不以食物为奖惩、不强迫）。

* **食物候选（非旗舰、家长确认）**：清晰餐前画面可给 "香蕉 / 燕麦" 候选，**家长一键确认才入账**；不推断混合菜、不做营养 / 热量 / 过敏原。

* **边界**：餐盘少了≠吃下去；不判食量 / 营养；不打 "吃得好不好" 分数，只记行为事实 + 回应式喂养提示。

* **文化共鸣（中国特色，落地报告补差评 / 帖子证据）**：隔代追喂、边吃边看动画、哄喂怕饿、强迫进食。

### 1.4 三档记录 + 随访证据包（中国版对接社区儿保）



1. **每周・家庭成长便签**：自动生成，3 条以内行为片段 + Firsts，轻、不打扰。

2. **每月・成长册**：WS/T 月龄里程碑对照（会走 / 会说 / 会吃），家长确认入册。

3. **随访节点・儿保沟通证据包**：对接国家基本公卫 0–6 随访（新生儿 / 满月 + **3、6、8、12、18、24、30、36 月龄共 8 次** + 4–6 岁每年 1 次），一键导出 / 分享给社区卫生服务中心儿保医生，可附进**母子健康手册 / 儿童健康管理档案**（对标英国 Red Book，但中国化）。

* **数据四标签**：画面 / 声音可见 ｜ 家长确认 ｜ 建议 ｜ 无法判断。

### 1.5 数据治理与合规（中国法 + 赛题红线）



* 端侧 / 本地（HomeBase/microSD）优先，**默认不上云、不用于训练**；未确认素材 **7 天自动删**，仅家长点选的精选长期保存。

* 合规：《个人信息保护法》最小必要；《儿童个人信息网络保护规定》（**14 岁以下监护人同意**）、《未成年人网络保护条例》；敏感场景（卧室 / 卫生间）默认遮罩、一键停采 / 删除、分享链接可过期可撤回。

* 赛题四红线逐条对齐：① 只检测行为不识别身份 ② 报警 / 删除 / 控制必须人确认 ③ 不留数据后患、未成年人保护 ④ 不作假：**mock 全程显著标注 "演示数据流（非预录实测）"，不破解固件、不换皮**。

## 二、代码实现方案

### 2.1 三个产物与工程目录




全部单文件、不引联网 CDN、不依赖构建；图标用**内联 SVG（不用 emoji）**。

### 2.2 app.html 技术架构（原生 JS，无框架、无 module）



* **视口**：390×844 手机框，桌面浏览器居中；舞台固定、不流式错位。

* **数据源适配层（关键，对应赛题 "接真设备"）**


  * `CameraSource`：`live`（eufy Web SDK / P2P 取流，预留）与 `mock`（脚本化演示帧）两实现；

  * `AudioSource`：`live`（soundcore/E21）与 `mock`；

  * 一行切换：`const DEMO_MODE = 'mock' | 'live'`；任何 mock 画面常驻角标 "演示数据流（非预录实测）"。

* **信号处理（mock 用确定性脚本，live 仅留接口与注释，不伪造能力）**


  * 运动：脚本地标 / 双脚离地 / 过线 → 距离（已知物体标定）→ Δ；

  * 语音：VAD 段 → 清晰 / 嘈杂判定 → 词 / 句 / 对话回合计数（mock 数值）；

  * 进餐：场景 → 看屏、时长、自主进食动作、饥饱手势、追喂。

* **证据状态机**：

  `candidate(画面/声音可见) → 家长三态确认 → confirmed 入册 | rejected；无效→unjudgeable 不生成`。

* **存储**：`localStorage`（演示）存里程碑、Firsts、时间轴、有效观察天数 / 片段数、设置。

* **mock 剧本**：预置一个 **24–30 月龄孩子的一周**数据，保证现场点击即走通三尖刀全闭环。

* 核心数据结构（示意）：



```
evidence = { id, blade:'walk|talk|eat', code:'hop\_over\_line|turn\_take|self\_spoon',

&#x20; observedAt, source:'vision|audio', status:'candidate|confirmed|rejected|unjudgeable',

&#x20; value, unit, confidence, parentNote, clipRef, expireAt /\*+7d\*/ }

milestone = { blade, code, monthExpect, wsDomain, status, firstAt }
```

### 2.3 三尖刀判定逻辑（伪代码，mock 可直接据此脚本化）



```
会走 hop\_over\_line:

&#x20; 检测双脚离地帧 t1 与落地帧 t2；用已知物体(胶带/门框)像素宽度标定 cm/px；

&#x20; 前进距离 d = (落地x - 起跳x) \* cm/px；双脚同时离地且 d>0 → candidate；

&#x20; 与该任务上一次 confirmed 的 d 求 Δ（单次纵向进步）；家长确认 → 入册。

会说 turn\_take / first\_words:

&#x20; VAD 切段；背景噪声超阈/多声源 → unjudgeable；

&#x20; 清晰段内按能量/停顿切"说话人交替"计 turn-taking 回合；

&#x20; 词/句仅在家长确认后入词表，去重新词=Firsts；句长达到月龄阈值(24月短句)给里程碑候选。

会吃 self\_feed / no\_screen / meal\_duration / responsive:

&#x20; 餐桌场景开始计时；识别勺/杯到嘴动作、手抓；

&#x20; 检测餐桌电子屏与孩子注视(看屏)；时长>20min 提示、>30min 标记；

&#x20; 识别成人端碗离开餐桌跟随=追喂；识别饥饱手势后成人是否回应；

&#x20; 食物：仅在餐前清晰帧弹"候选：香蕉/燕麦"，家长确认才写入，不进营养计算。
```
