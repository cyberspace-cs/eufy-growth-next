01
OVERVIEW

系统总览与五层架构

设计原则对照 AdventureX 2026 获奖作品

层位置职责关键约束
采集层server/camera-agent/adapters/信号源适配：mock（确定性脚本）· eufy SDK（预留）· RTSP（预留）信号是适配器与管道的唯一契约；换真实 SDK 只改本层
信号层adapters 输出帧间运动量 / VAD 语音活动段 / 餐具运动周期 / 屏幕标志原始信号带时间戳，可回放测试
判定层pipeline/{walk,talk,eat}.mjs纯代码状态机 + 阈值 + 标定换算 → candidate永远不经 LLM；无法测量保留原因，不写零分
证据层pipeline/engine.mjs + index.mjscandidate 登记、审计日志、SSE 推送、三态确认 REST会话制（家长显式开启）；候选不自动入册
表述层src/core/rules.ts + server/llm-gateway/PHRASE 确定性文案 + LLM 可选润色LLM 只收已确认结构化记录；无 key 降级本地模板

原则来源：Night Watch（信号→置信度→决策全程留痕、同意优先会话制）、FinSight（确定性计算交给代码，LLM 只解释）、Fiona（主路判定/旁路表述物理分离）、冰箱精灵（双端实时同步 → 本方案用 SSE 实现，纯 HTTP 穿透任何静态网关，无需 WebSocket 升级）。

03
DATA MODEL

数据模型

核心事件字段 · 版本与权限

字段类型说明
id / blade / codestring事件标识；尖刀（walk/talk/eat）；观察类型 code（对应 OBS 目录）
observedAt / sourcestring时间戳；来源：vision / audio / demo（真机接入后增 sdk）
levelenum四色来源标签：visible / parent / suggestion / unknown —— 全站每条输出必带其一
status / trienumcandidate / confirmed / rejected / unjudgeable；三态 done / sometimes / notyet
value / confidencestring / 0—1人读描述；判定置信度（状态机给出，非模型输出）
distCm / words / foods可空观测距离（同任务差值用）；词/句候选；食物候选（确认才入账）
protocolVersion / calibrationIdM2 计划任务协议版本与标定批次——同条件比较的判定依据（路线图）

关联原则：通过同一事件 id 关联画面与声音，避免把不同孩子、不同餐次或不同时间拼成一条事实。保留原始候选与纠错记录，重新生成报告时只用最新已确认版本。导出文件为唯一跨设备载体（无账号后端时不自动同步）。

04
STATE MACHINES

判定层状态机

三管道迁移表 · 阈值与降级

walk · 跳跃状态机

状态迁移条件动作
standingmotion ≥ 0.85 或 phase=takeoff→ possible_takeoff
possible_takeoffmotion ∈ [0.5, 0.8]→ possible_airborne（记 tAir）
possible_airbornemotion ≥ 0.85 且 phase=landing出候选：distCm = disp_px × 5cm / 12.4px；confidence = min(0.95, 0.55 + 0.4 × clarity)；→ standing
任意非 standing3 秒未迁移审计日志记录原因，重置 standing（不写零分）

clarity < 0.7 时候选自动附注「落地帧脚部略糊，需家长确认」并压低置信度——E2E 实测：清晰帧 0.93 / 0.91，模糊帧 0.77。

talk · 回合计数

voice-on/off 事件流；相邻段间隔 ≤2.5s 计一个回合；会话结束输出 turn_take 候选（附「VAD 只测语音活动，不做说话人分离」注记）。出现 overlap 标志（双声源）→ 直接出 unjudgeable 候选，回合候选不产出——多声源不出提示。

eat · 周期统计

分钟级采样：举勺周期 ≥8 次/分 记自主段，≤4 次/分 记疑似喂饭段；屏幕在场累计 ≥5 分钟触发 no_screen 候选；会话结束出 meal_duration（附「会话起止计时，不宣称实际进食时长」）。追喂候选附注「指南要求不强迫进食，请家长确认」。

05
ADAPTERS

采集层适配器与验收清单

mock 可运行 · SDK/RTSP 预留位

MockSource：确定性脚本（非预录视频）。三段剧本：walk 3 跳（58/61/47px，第三次模糊）、talk 6 回合+1 双声源、eat 21 分钟（前 12 分钟自主、后段喂、12—19 分钟屏幕）。tick 加速播放（walk/talk 220ms、eat 320ms 每模拟单位）。

EufySDKSource（预留，抛错不冒充）：接入验收清单——① 登录与设备列表；② 前台短时取流稳定（不承诺电池设备全天采集）；③ 帧可绘入 canvas；④ 音轨/时间戳/有效帧率；⑤ 事件主动拉取（无 push 配置）。全部通过前不产生真实里程碑，不发明 API 名称。

RTSPSource（预留）：ffmpeg 抽帧方案已写明参数（-vf fps=4,scale=640:-1 image2pipe），帧差信号 motion = mean(|gray_t − gray_{t−1}|)/255 与管道契约一致；本机不编译 ffmpeg，仅在具备环境的服务器路径生效。

06
API & SSE

API 与 SSE 协议

六个端点 · 五类事件

方法路径说明
GET/api/health服务与当前会话状态（注：Page 网关保留 /healthz，故用 /api/health）
POST/api/session/start{blade} 开启采集会话；自动停上一会话并记原因
POST/api/session/stop家长手动结束（同意优先）
GET/api/streamSSE：signal / state / candidate / candidate-updated / session-start / session-end / audit
GET/api/candidates当前候选 + 最近 20 条审计
POST/api/candidates/:id/confirm{tri: done|sometimes|notyet|reject}；更新后广播 candidate-updated

事件均带 sessionId 与时间戳；candidate 事件在引擎侧登记后广播（管道只发事件，存储归 SessionManager）。SSE 15s 心跳防断连；req close 时退订。

07
DISCIPLINE

表述纪律工程化

把「原则检验」变成可执行脚本

PHRASE 函数：所有面向用户的文案只能经 rules.ts 的 PHRASE 生成——firstRecord 不写「人生第一次」、noSample 输出「未获得可判断样本，不等同于不会」、modeled 标注「成人示范后完成」、plateChange 不换算摄入、occluded 不评价独立性、deltaNote 永远带「个体记录，非标准阈值」。

FORBIDDEN + 构建期校验：check-discipline.mjs 扫描 src/ 全部 ts/tsx/html/md，命中禁词即 exit 1（CI 可挂）。已处理两类误报：FORBIDDEN 数组自引用（strip 定义块）、继承旧交付物的否定语境文案（「不做 XX」声明不扫描，规则写入脚本注释）。当前状态：0 违规通过。

四色标签强制：LEVEL_META 全站唯一出处；报告只用 confirmed；pending 数与覆盖说明永远显示。

08
LLM GATEWAY

LLM 网关边界

只做两件事 · 三层防护 · 降级可演示

端点：POST /api/activity（下周陪玩文案）、POST /api/summary（儿保沟通摘要）。输入过滤：只接受 status=confirmed 的结构化记录，无已确认记录返回 422。系统提示词内置禁词清单与五条铁律（不诊断/不评分/不排名/不推测记录外能力/建议必须挂证据编号）。供应商：deepseek / qwen / ark 三选一，经 env 注入（LLM_PROVIDER / LLM_API_KEY / LLM_MODEL / LLM_BASE_URL），密钥永不入库。降级：无 key 或调用失败 → 返回本地模板文案并标 degraded:true——比赛演示永不因模型中断。默认不发送儿童原始音视频。

09
FRONTEND

前端架构

双布局 · Live 页 · i18n 规划

React 18 函数组件 + Context store（localStorage 持久化，SSR 安全 try/catch）。五页：今天（反直觉开场+一天时间线+三尖刀卡）、实时（EventSource 接 /api/stream，会话按钮+事件控制台+行内三态确认）、待确认（剧本候选复核）、周报（buildReport 只读已确认）、设置（信任设计面板+数据源状态）。响应式：≤768px 手机底导（safe-area 适配），桌面侧栏双栏。

i18n（M3 计划）：文案字典抽离 zh/en 两包；英国包替换：WS/T→ASQ-3 对照、儿保→health visitor、客厅机位→花园机位、母子健康手册→Red Book；语言切换不改数据结构与状态机（内容配置与代码分离原则）。
