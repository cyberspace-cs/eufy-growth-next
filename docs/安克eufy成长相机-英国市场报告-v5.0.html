段 1 · 痛点定位

市场机会是沟通成本，不是「没有儿保」

主张行：这是全篇最容易写错的一句。把它写对，后面所有论证都站得住。
⚠️
撤回 旧稿逻辑：NCMP 不测运动 → 英国儿保存在空白 → 我们填补空白

改为主线：已有服务在做发育评估，家庭视频能补充的是「情境」；而情境能不能被专业服务接受、 值不值得家长多花操作，才是本项目的真问题。 「NCMP 不测运动」只能推导出「法定测量项目里没有运动」，推导不出「没人记录动作发展」。

为什么这个措辞差别很大

「填补儿保空白」= 你在替代公共服务 = 立刻面对监管与专业正当性质疑。
「补充已有访视之间的家庭材料」= 你在帮家长把想说的话说清楚 = 位置小、但守得住。

一句能钉死定位的官方原文

「仅靠视频、电话或邮寄问卷完成的 review 不满足法定 review 标准，不得上报为已完成的法定 review。」

这一句同时干两件事：挡掉「你在替代 NHS」的质疑，又证明 「两次 review 之间的空白」是官方承认存在的空间——这个空间不用你自己论证。

来源：GOV.UK · Delivery of the Healthy Child Programme · Part 2: Health visiting (ages 0 to 5) · 2026

首批家庭画像 修改

接近 3 岁、有陪玩意愿、愿意复核短片段，并有 health visitor 或 nursery 沟通需求，优先已有兼容 eufy 设备的家庭。

本版新增一条硬约束：家里有可固定机位，且活动区地面平整。 理由：地面四点标定是首版唯一的技术门槛；试点家庭地面不平或没有固定机位，失败率会全算在算法上，得不出有效结论。

不以「设备用户多」直接换算为儿童功能潜在客户——这两件事之间没有已验证的转化关系。

现有替代方案（这些才是真正的竞争对手）

英国用户的真实替代不是美系母婴品牌，而是：手机录像 + 纸质 Red Book + Mumsnet 社区 + 现有安防摄像头回放。 它们缺少的可能是自动整理，而不是录音录像本身。产品必须证明「找片段 + 解释上下文」比这些方式省事。

为什么入口收敛到「接近 3 岁」

  • 政策节点对上：英格兰 2—2½ 岁有 universal review，家长这段时间本来就要准备跟专业人员沟通。
  • 动作可观察：双脚向前跳是全身动作、起落点明确，固定机位能拍到脚部与地面。

一个必须承认的张力

报告的核心场景是室内地面上的幼儿运动（标定矩形、起跳线、门框参照——全是室内几何）， 但赛题现场只给两台室外机，且明确把「摄像头只当远程查看的窗」「摄像头当录像机」列为排除项。

但赛题第一个开放式问题就是「把摄像头拿掉，作品还成立吗？」——不成立才叫主角。 几何标定方案（已知边长矩形 + 地面共面 + 单应变换）恰恰是只有摄像头能做、手机录像做不了的东西， 这一点该被顶到最前面去讲。M11 选的「花园为主场景」正好把室外机的限制转成了场景优势。
