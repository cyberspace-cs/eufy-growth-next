1　决策摘要（中国版） 新增·中国

一句话：不新增硬件、不制造焦虑——复用家庭已部署的 eufy 机位，把「会走、会说、会吃」的行为事实自动沉淀为候选证据，家长三态确认后入册，在 8 次社区随访时成为儿保医生看得懂的沟通材料。

要素结论
目标用户0–6 岁（旗舰演示固定 24–30 月龄）儿童家庭，含隔代照护场景；下游使用者为社区卫生服务中心儿保医生。
核心场景客厅活动区（会走）、共读 / 游戏桌近端音频（会说）、餐桌（会吃）。
政策理由五健之健康骨骼、健康心理（筛查率 2030 达 90%，原文鼓励数智技术分级分类管理）、健康体重；能力目录对齐 WS/T 580 / WS/T 479 与早期发展指南。
差异化红线即差异：不诊断、不评分排名、不识别身份、不做营养；机器只做记录与分流，诊断权留给医生。
演示形态390×844 单文件离线手机 demo（app.html）；mock 确定性脚本 + live 本机真实取流双数据源；预置 26 月龄孩子一周剧本。
诚实前提赛道发放的是室外机，室内机位为最大变量；默认 mock + 适配层，明确标注，不靠预录冒充。

3　产品定义与四条红线 修改

3.1 定位与“魂”

家长要的不是“检测到运动 / 声音”，而是“我知道孩子好好的、在按时长大”——把不确定变确定。产品只做两件事：在家长看不到 / 记不住的时候替家庭留住行为事实；在随访场景替医生准备沟通材料。

3.2 四条不做（一票否决项）

不做诊断与评分

不做发育商 / 发育评分 / 排名，不判“语言迟缓”“智商高低”；持续异常只提示借随访咨询医生。

不做视觉营养师

不猜混合食材、不算热量营养、不判过敏原（详见 §8.3 删除说明）。

不识别身份

无人脸识别、无声纹识别，不识别“是谁”；机位只输出行为候选。

不作假

不预录冒充、不换皮、不交付只接不到真设备的纯界面；mock 全程显著标注。

3.3 数据四标签（全站每条输出必带其一）

画面/声音可见 机器直接观察到的行为事实； 家长确认 经三态确认 / 勾选后入册； 建议 不带判定的行动提示； 无法判断 遮挡 / 嘈杂 / 样本不足，不生成结论。

4　尖刀一 · 会走：兔子跳过线 保留修改

4.1 月龄窗与黄金锚点

月龄窗 12–36 月，旗舰聚焦 24–30 月。WS/T 580 大运动能区 + 早期发展指南：24 月跑稳能停、双脚同时离地原地跳、不扶摆腿踢大球；30 月双脚向前跳；36 月交替脚上楼 / 单脚站。

4.2 旗舰任务「兔子跳过线」

① 已知物体标定地上贴胶带（或门框 / 已知宽度铺路板），不做精确深度测距
② 逐帧姿态双脚离地帧 t1、落地帧 t2；像素换算 cm/px
③ 过线判定双脚同时离地且前进距离 d>0 → 候选
④ 三态确认做到了 / 有时会 / 还不会，家长确认入册
⑤ 个体 Δ与自己上一次 confirmed 距离比较，只做纵向记录
距离口径（相对英国版的关键修改）：临床锚点只用月龄里程碑“能不能向前跳”，不挂英国百分位；演示中 18.0cm → 23.5cm 的 +5.5cm 是“个体记录”，不是标准阈值、不与其他孩子比较。

4.3 四张任务卡

红灯停绿灯行（跑停）／袋鼠原地跳／踢纸球／兔子跳过线（旗舰）。

4.4 诚实边界 保留

  • 家用单摄对扶走、遮挡场景识别率低（英国版调研外部证据约 38.9%，作为量级参考沿用，中国场景待复测）；
  • 没拍到 ≠ 不会：固定报告“有效观察天数 / 清晰片段数”，遮挡片段直接丢弃、不评价；
  • 倒退、单侧不对称、持续踮脚等异常步态：只提示就医、不做判断。

5　尖刀二 · 会说：对话回合与 Firsts 新增·中国

5.1 为什么“会说”是中国版必选项

五健文件把 0–6 岁儿童心理行为发育筛查（监测）比例 2030 年达到 90% 写为硬指标，并原文鼓励数智技术做分级分类精细化管理。家庭端的行为记录，正是社区筛查体系最缺的“两次随访之间”的素材。

5.2 月龄锚（早期发展服务指南原文）

月龄语言里程碑demo 对应
12 月听懂 ≥1 个物品名共同注意辅助
18 月说出 3 个有意义的词家长确认新词去重计数
24 月说简单句子旗舰：3 字短句 Firsts（“我要香蕉”）
30 月回答简单问题对话回合趋势
36 月说出简单故事大部分情节下一代扩展

5.3 只做三件最稳的行为层

  1. 回应式对话回合：家长说 → 孩子应 → 家长接的 turn-taking 计数，不要求识别每个词；
  2. 家长确认的新词 / 短句 Firsts：候选文本可由家长改正，确认后去重入词表；
  3. 共同注意：成人指 / 看 → 孩子追视 / 指物（视觉辅助）。

5.4 判定与最硬边界

  • VAD 切清晰语音段；背景噪声超阈 / 多声源 → 直接标 无法判断，demo 中“电视 + 三人说话”片段即如此处理；
  • 幼儿远场 ASR 错误率高：只给趋势与样本，不下语言诊断、不输出词汇量 / 语言年龄；
  • 不做声纹 / 身份识别；样本不足不出提示；
  • 样本充足且持续低于月龄预期时，只建议借 30 月龄社区随访向儿保医生咨询——机器分流，医生诊断。

8　数据诚实边界与删除清单

8.1 什么自动采 保留

机位内、任务卡定义内、清晰度达标的行为候选：动作类别、时间戳、置信度、（会走）已知物体标定距离、（会说）回合数与候选转写、（会吃）时长 / 看屏 / 追喂 / 自主进食。

8.2 什么只靠家长、什么不碰 保留

  • 三态确认、食物勾选、词 / 句改正、备注、是否入册与分享：全部家长动作；
  • 不碰：身份（人脸 / 声纹）、诊断结论、评分排名、营养热量、过敏原、食量、画面外行为、情绪定性。

8.3 营养估算整段删除说明 删除 / 本期不做

删除项（英国 V2.1 食物识别分层与营养 / 热量估算）：
不推断混合菜品、不估算克数与热量、不做营养素与过敏原判断、不输出膳食评分。
删除理由：① 家用单摄对中餐混合菜肴可靠性不足，错误的营养结论比没有结论更有害；② 健康体重的政策锚点可由喂养行为（回应式、不看屏、时长、不强迫）直接承接，这些均为指南原话且视觉可判定；③ 红线清晰有助于现场答辩。食物仅保留“餐前清晰帧候选 + 家长确认”一档。

8.4 词表纪律（demo 已内置校验口径）

全站禁止出现：发育商、语言年龄、同龄百分位、智商、专注力分数、教学评分、营养诊断、达标、落后、人生第一次、掌握了、排名。首次记录统一表述为“本系统首次记录到……”；无样本统一表述为“未获得可判断样本，不等同于不会”。

13　评委 Q&A（12 问，按三尖刀重写） 修改

1. 这和普通摄像头的“运动检测 / 哭声检测”有什么区别？
运动检测输出的是信号，我们输出的是带月龄锚点、经家长确认的行为记录，并且终点是随访沟通材料；信号是中间产物，不是产品。
2. 不做诊断，价值在哪里？
五健 90% 心理筛查目标缺的不是诊断者（医生在），而是两次随访之间的家庭观察素材。我们做记录与分流，把诊断权完整留给儿保医生，这恰是合规可持续的位置。
3. 赛道发的是室外机，你们是不是在做接不到设备的纯界面？
不是。demo 默认 mock 且全程显著标注；live 模式在本机摄像头 / 麦克风上跑真实取流与真实信号（帧间运动量、VAD）；S350 / E21 的 SDK 接入位预留。室外机的机位差距在报告与设置页明示，不回避。
4.（会走）凭一条胶带就能测跳多远？
我们不做精确深度测距，只用已知宽度物体做像素标定，且临床结论只用月龄里程碑“能不能双脚向前跳”；距离只用于同一个孩子的纵向 Δ，不做横向比较。
5.（会走）没拍到跳，会不会误报“发育落后”？
永远不会。遮挡 / 扶走片段丢弃；无样本时成长册显示“本周未获得可判断样本”，并固定披露有效观察天数与清晰片段数；没拍到 ≠ 不会。
6.（会说）远场语音识别那么差，你们怎么保证可信？
我们不依赖远场 ASR：只数对话回合（能量 / 停顿 + 说话人交替），词和句必须家长确认 / 改正后才入册；嘈杂多声源直接无法判断，不硬猜。
7.（会说）会不会给孩子贴“语言迟缓”标签？
不会。不输出词汇量、语言年龄、诊断标签；样本充足且持续偏低时，只建议借 30 月龄随访咨询医生。系统不做声纹、不识别是谁。
8.（会吃）为什么不做营养识别？这不是家长刚需吗？
中餐混合菜肴的视觉营养识别可靠性不足，错误结论有害。健康体重锚点用喂养行为承接（回应式、不看屏、约 20 分钟、不强迫），全部是指南原话、可视觉判定；食物只给候选、家长确认。
9.（会吃）追喂判定错了怎么办？
追喂只是候选，由家长三态确认；不入诊断、不评分。确认后的记录用于随访沟通与家庭喂养提示，家长可随时排除或删除。
10. 孩子视频上云吗？会被拿去训练吗？
默认端侧 / 本地、不上云、不用于训练（demo 中为不可关闭承诺）；训练授权单独勾选；未确认素材 7 天自动删，分享链接可过期撤回。
11. 14 岁以下监护人同意怎么落实？
按《儿童个人信息网络保护规定》，首次启用设置监护人同意流程与专门儿童信息处理规则；demo 隐私页展示告知口径，正式版做成可审计的同意记录。
12. 下一步是什么？
短期：补中国差评 / 帖子取证、接 S350 SDK 跑通常温真设备；中期：视力 / 口腔机位与户外多机位；全程坚持“行为记录 + 家长确认 + 医生沟通”的边界。
