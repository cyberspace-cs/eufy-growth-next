Deploy Pipeline · 部署管线

本地 git push，服务器自动构建并上线

三个裸仓库各带一个 post-receive hook。推上去就自动检出、构建、同步到 webroot，动态版还会重启 Agent 服务。不用登服务器。

01本地 pushgit push demo main 推到你自己的服务器裸仓库
02hook 检出post-receive 把 main 检出到 ~/eufy-demo/apps/<name>
03构建装依赖 → 跑禁词校验 → 构建（动态版按子路径 base 构建）
04上线rsync 到 /var/www/eufy-demo/<name>，动态版 systemctl restart
Maintain · 维护方式

三条命令管三个 demo

首次在本地仓库加一次 remote，之后只用 push。

# 一次性：加远程（三个仓库各加一次）
git remote add demo ssh://ubuntu@43.143.231.106/home/ubuntu/eufy-demo/repos/eufy-growth-next.git

# 之后：改完就发
git push demo main            # next   → /eufy-demo/next/
git push demo main            # cn     → /eufy-demo/cn/
git push demo main            # react  → /eufy-demo/react/

# 服务器侧排障
systemctl status eufy-next    # 摄像头 Agent 服务
tail -f ~/eufy-demo/logs/eufy-next.log

线上拓扑

  • /eufy-demo/ 本页（门户）
  • /eufy-demo/cn/ 纯静态 · /var/www/eufy-demo/cn
